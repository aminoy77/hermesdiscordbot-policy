# Política de Privacidad (Privacy Policy)

**Última actualización:** 5 de octubre de 2026

## 1. Información que Recopilamos
- **Identificadores de Discord:** Para el correcto funcionamiento del servicio, el Bot procesa el ID de usuario (`User ID`), ID de servidor (`Guild ID`) e ID de canal (`Channel ID`).
- **Contenido de Mensajes:** Los mensajes dirigidos o mencionados al Bot se procesan temporalmente para generar las respuestas correspondientes.

## 2. Uso de la Información
La información procesada se utiliza exclusivamente para:
- Responder a las solicitudes y comandos enviados por los usuarios.
- Gestionar los permisos de acceso y configuración de la aplicación.

## 3. Almacenamiento y Seguridad
- No vendemos ni compartimos datos personales con terceros.
- Los datos de las conversaciones no se almacenan de forma permanente a menos que sea estrictamente necesario para el historial de contexto de la sesión.

## 4. Contacto y Eliminación de Datos
Si deseas solicitar la eliminación de cualquier dato asociado a tu usuario o servidor, puedes contactar con el propietario del bot a través de Discord.
